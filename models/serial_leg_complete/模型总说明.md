# 串腿轮足机器人 MJCF 模型：总说明

## 从哪里开始

建议使用 `outputs/serial_leg_passive_limits_preview.zip`。解压后保留 XML 与 `meshes` 的相对目录：

```text
robot_passive_limits.xml    MuJoCo 机器人模型入口
README_限位说明.md           腿部限位与验证说明
meshes/                    62 个 XML 引用的 STL 网格
```

本工作区另有 `outputs/fusion_script_archive/` 和 `outputs/fusion_script_archive.zip`，保存 Fusion 脚本及部分离线辅助代码。`work/` 是建模、扫描、结果和验证过程的工作目录，`outputs/` 下其他 `draft`、`left_right`、`zero_preview`、`limit_preview`、`guard_candidate` 等是历史或中间版本，避免与当前模型混淆。

## 模型包含什么

- `robot_passive_limits.xml` 包含机身、左右腿、轮子、云台、闭链连接、驱动器、碰撞几何与底盘 IMU；机身在 XML 中命名为 `base`，对应本项目的 base link。
- `meshes/base_hipclean_part*.stl`、`yaw.stl`、`pitch_part*.stl` 分别是机身、云台 yaw、云台 pitch 的视觉网格。
- `left_*`、`right_*` 是两侧对应部件的网格；`thigh` 大腿、`output` 小腿输出端、`calf` 小腿、`longbar` 长杆、`midbar` 中杆、`shortbar` 短杆、`wheel` 轮子。`hardware_*`、`*_sprocket`、`hip_adapter` 和 `wheel_*` 包含附属视觉零件。
- `*_simple_collision.stl` 是连杆的简化碰撞网格。轮子碰撞用 XML 圆柱；机身及云台碰撞用盒子。视觉网格不参与碰撞。当前机器人碰撞几何为 `contype=1`、`conaffinity=2`，彼此不会直接产生自碰撞；模型内没有地面。

## 关节与驱动

左右依据用户指定的机身前视方向命名；在当前 XML 的初始 `base` 坐标下，`right` 髋轴位于 +Y，`left` 位于 −Y。检查其他工具或控制器坐标方向时应以实际变换和关节轴为准。

每侧各有两个同轴髋驱动和一个轮驱动：`{side}_hip_thigh_motor`、`{side}_hip_output_motor`、`{side}_wheel_joint_motor`，对应同名去掉 `_motor` 的关节。六个 motor 的 `gear=1`；链轮本身只保留视觉几何，没有仿真链传动。云台有 `yaw_joint`、`pitch_joint`，但当前 XML 未添加云台 actuator。

每侧的 `{side}_knee`、`{side}_longbar_joint`、`{side}_midbar_joint`、`{side}_shortbar_joint` 是被动关节。XML 用四个 `equality/connect` 连接左右闭链；调整模型时要保留对应 site 和连接关系。

## 零位及腿部限位

零位以机身水平、腿缩短、轮轴与髋轴连线竖直为依据。`output` 和 `thigh` 未分别设置固定上下限；两个关节相对角度通过 fixed tendon 约束为 `output − thigh = -2.529066～0 rad`。两者一起转动与改变相对角度是不同的运动。

| 被动关节 | 计算范围（rad，相对零位） |
| --- | --- |
| knee | −1.817599～0 |
| longbar_joint | −1.817599～0 |
| midbar_joint | −0.057419～1.106132 |
| shortbar_joint | 0～1.817599 |

除 knee 外，XML 在这些计算范围的两端各增加 0.001 rad 数值容差。中杆的最小值出现在运动中间。限位依据 Fusion 主要连杆实体的离散干涉采样与闭链计算；用户已指定链轮不参与限位判断。采样不是连续空间的严格证明。

## IMU、单位和仿真状态

`chassis_imu` site 隶属 `base`，当前位置 `pos="0 0 0"`、方向为单位四元数，是占位安装位姿；需要按实际底盘 IMU 安装位置和方向修改。传感器为 `chassis_imu_gyro`、`chassis_imu_accel` 和 `chassis_imu_quat`。

XML 使用弧度；网格声明中的 0.001 缩放将 STL 尺寸转换为模型长度单位。XML 内 `gravity="0 0 0"`，base 没有自由关节，处于固定底座预览状态；17 个刚体的质量、质心和惯量取自 Fusion「串腿车架 v6」2026-11-07 20:38（北京时间）的可见实体，共 30.911 kg。inertial 的 pos 为刚体局部质心（m），fullinertia 为沿刚体局部轴表达、绕质心的惯量（kg·m²）。模型没有地面和完整动力学环境，不能直接当成实车安全限位或训练就绪模型。

## 查看与验证

在 Robot Viewer 中加载 XML **及全部 STL**，可显示绑定网格、关节和闭链；启用碰撞显示可检查近似包络。查看器的姿态编辑器未必执行 MuJoCo 的所有动态约束：本模型额外设置膝关节范围以辅助查看器拒绝部分超限姿态。髋关节滑块显示范围不等于实际独立硬限位。

当前结果已在 MuJoCo 加载；301 个左右腿对应姿态通过闭链和关节范围数值检查，2,000 个区间内网格采样没有发现新增相交。用户指定不检查链轮；其他附属件、实际装配间隙、电机、电缆、地面接触及动力学仍需另行核对。
