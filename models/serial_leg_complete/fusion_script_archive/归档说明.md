# 脚本归档说明

本目录保存本次项目结束时 Fusion 脚本的当前磁盘快照，不代表每个同名脚本在工作过程中曾运行过的所有历史版本。脚本绑定了此计算机的绝对路径、Fusion 组件完整名称和特定装配，复用前必须检查并调整。部分脚本会写出或覆盖结果文件；BaseSplit、WheelInspect 等涉及临时可见性操作，应先检查恢复逻辑。Fusion 脚本仅可在 Fusion 的 Python 环境中运行，不是普通 Python 脚本。

## fusion/

- CodexInspect：枚举装配、几何和变换。
- CodexAxes、CodexGimbal：读取轴线或云台相关几何。
- CodexExport、CodexHardware、CodexBaseSplit、CodexSprocket：按项目分组导出模型及附件网格。
- CodexWheelInspect：检查轮组相关几何。
- CodexRelativeSweep：对给定姿态中的主要连杆进行 Fusion 实体相交扫描。
- CodexSolidCheck：检查主要连杆、轮组与车体的采样干涉。
- CodexSprocketAudit、CodexSprocketRange：检查指定链轮相关干涉。最终限位按用户要求忽略链轮。
- CodexOverlapLocation：用于定位重叠区域的后续草稿，归档时尚未确认成功运行。

每个子目录中的 manifest 与同名 .py 是 Fusion 脚本注册文件与代码快照。它们仍保留原始硬编码路径；不要在未阅读代码前直接运行。

## support/ 与 data/

support/ 是生成姿态、分析闭链、拟合限位和验证的普通 Python 脚本快照，依赖的具体包、输入文件、目录需分别检查。data/ 是部分输入变换和元数据快照，不包含完整工作目录、模型或所有中间结果；这些快照不足以保证从头重跑。完整当前模型请使用 `serial_leg_passive_limits_preview.zip`。

原始 Fusion 脚本仍保留在 Autodesk Fusion 360 的 API/Scripts 目录，归档未删除或修改原件。
