# 主要连杆关节限位预览

按用户要求，左右腿以缩短、轮轴与髋轴竖直对齐时为零位；大腿和 output 的同轴驱动关节未设置单独角度限位。两驱动之间受闭链活动范围约束，不能把两个髋关节的允许值视为互相独立的固定区间。

左右腿使用同一数值约定：

| 被动关节 | 根据闭链计算的相对零位活动范围（rad） |
| --- | --- |
| 膝关节 knee | -1.817599 到 0 |
| 长杆 longbar_joint | -1.817599 到 0 |
| 中杆 midbar_joint | -0.057419 到 1.106132 |
| 短杆 shortbar_joint | 0 到 1.817599 |

中杆的最小值出现在行程中部，而不是两个端点。除膝关节外，XML 中每侧上下限各留 0.001 rad 数值容差，以免求解误差挡住可行位置。MuJoCo 使用 output - thigh 的固定腱范围 -2.529066 到 0 rad 表达联动边界，Viewer 通过被动膝关节检查闭链范围。

Fusion 对主要连杆的实体采样用于找出伸缩两端；2000 个区间内姿态的三角网格检查没有发现新增相交。按用户确认，链轮不参与限位判断。采样不构成连续空间严格证明；附属件、电缆、电机、实物间隙和安全裕量没有包含。质量、质心和惯量来自当前 Fusion 可见装配，重力为预览设置，不可直接用于实车安全保护。
